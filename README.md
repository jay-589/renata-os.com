# Renata OS website

Static marketing site for Renata OS, prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository and push this project to its `main` branch.
2. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. The included workflow deploys the `dist/` folder whenever `main` changes.
4. In **Settings → Pages**, enter `renata-os.com` as the custom domain and enable **Enforce HTTPS** when GitHub makes it available.
5. Only after GitHub confirms the custom domain, replace the current website DNS records with GitHub's records. Keep existing email MX, SPF, and DKIM records unchanged.

## Important

GitHub Pages is public hosting. Do not add research data, passwords, credentials, or private demo materials to this repository or the `dist/` folder.
